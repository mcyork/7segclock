7segclock

An NTP clock on four WS2812 seven-segment digits, driven by an ESP32-C3 Super Mini. Flash it from this page — no toolchain, no drivers.

After flashing

  1. The display shows AP and raises a network called mini7seg-clock. Password sevenseg.
  2. Join it; the setup page should open by itself. If not, browse to 192.168.4.1.
  3. Enter your wifi. It restarts, finds the time, and is then at mini7seg.local.

Timezone: this build shows US Pacific time (America/Los_Angeles, DST handled). A timezone setting on the settings page is planned for the next firmware; until then, other zones need a rebuild with TZ_STRING changed in src/main.cpp.

Trust model: the settings page, firmware upload and update endpoints have no password — anyone on your network can use them. Run it on a network you trust.

Wiring

Three wires from the C3, all on one edge of the board:

  1. 5V → panel H1 V
  2. G → panel H1 G
  3. GPIO4 → panel H1 DI

Any pin the settings page offers will do — GPIO4 is just the default. Solder to whichever is convenient and pick it under Hardware.

Updating later

You do not need this page to update — the clock can do it itself. Open mini7seg.local, and under Firmware press Check for updates. If there is a newer build it will fetch and install it on its own.

This page is still the one you want for a new device, or to recover one that will not boot.
